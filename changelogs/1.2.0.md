PlanCake 1.2: signed by Oire Software, and quieter task lists with a screen reader.

- The installer, its uninstaller and plancake.exe now carry Oire Software's digital signature: Windows' permission prompt names Oire Software as the verified publisher, and a file's Properties show the signature on the Digital Signatures tab
- The publisher in Windows' list of installed apps is now Oire Software, the company's name as registered
- A screen reader now calls every task-list checkbox "Done", followed by its state, instead of the task's first sentence, so reading a plan line by line or on a braille display no longer repeats the start of each task
