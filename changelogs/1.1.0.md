PlanCake 1.1: plans in WSL, and opening Markdown files from File Explorer.

- A plan in WSL, or on a network share or drive, now reloads when it changes on disk, as a plan on a local disk does; the manual's new "Plans in WSL" section shows how to open a plan from WSL
- PlanCake is now listed among the programs that open .md and .markdown files, in Open with and in Windows Settings, Default apps; the program you chose keeps opening them until you choose PlanCake
- Settings, Advanced has a new button that opens PlanCake's page in Default apps, where you can make it the default
- The installer no longer shows the Ready to Install page; the button on the page before it says Install
