First release of PlanCake: read Markdown files comfortably and leave notes right where they belong.

- Read Markdown as a document, with real headings, lists, tables and code blocks
- Click a block, or press Enter on it, to leave a note; it is written straight into the file, right after that block
- See your notes in the document and in a list beside it; edit, delete, jump between them with F9, and undo anything
- Check off task-list items from the document
- Open files from the command line, the Open dialog, drag and drop, the clipboard or a link
- Keeps your reading place when the file changes on disk, and never writes over a change you have not seen
- Command line for scripts and AI assistants: list, check, clear and export
- Works equally well with the mouse, the keyboard alone and a screen reader
- In English, Russian, Ukrainian, French, Hebrew and German
